# 腾讯云安全组与 HTTPS 模板

由用户在自己的云账号内配置，本仓库没有执行云操作。

| 方向 | 端口 | 来源 | 用途 |
|---|---|---|---|
| 入站 | TCP 22 | 用户固定管理 IP/32 | SSH，仅密钥登录 |
| 入站 | TCP 443 | 用户允许的客户端范围 | 正式 HTTPS；首次验收仅管理 IP |
| 入站 | TCP 80 | 证书校验需要的范围 | ACME 验证和跳转；不承担明文登录 |
| 入站 | 3306、6379、8080、18088、18089 | 无 | 不开放 |
| 出站 | DNS、HTTPS、时间同步 | 按实际依赖限制 | 镜像、微信、AI、OSS、证书更新 |

容器 Nginx 默认绑定 127.0.0.1。主机 TLS Nginx 使用 https.conf.example，先替换域名及证书路径，再 nginx -t。复制 proxy_params 到模板所指路径；域名 A/AAAA、证书链、自动续期、HTTPS 重定向均需实测。反向代理链上线前明确可信代理地址，避免将客户端伪造的 X-Forwarded-For 当成可信身份。

当前后台静态页面公开提供登录界面，业务 API 校验身份；可进一步给 /admin 与管理员 API 增加 IP 或 VPN 限制。微信 request 合法域名与 OSS 资源域名分别配置，开发工具跳过域名校验不能替代真机验收。OSS 按对象访问权限或临时签名授权，不把整个私有桶改为公开。仓库仅使用图片 URL，没有 OSS 上传 SDK/签名刷新流程。
